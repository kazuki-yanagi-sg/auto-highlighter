# 安全リファクタリング

**仕様を絶対に壊さない**ことを前提とした安全なリファクタリング。

## 引数の処理

引数: $ARGUMENTS

- 引数指定時: その対象に限定したリファクタリング
- 引数未指定時: 現在ブランチの修正範囲に限定

## 実行フロー

1. **現状把握**: テスト状況・ブランチ差分確認
2. **影響分析**: 依存関係・リスク評価
3. **安全な実行**: 小単位での段階的変更
4. **品質確認**: 型チェック・テスト・lint成功

## 安全に実行可能な範囲

✅ 内部実装改善（外部インターフェース維持）
✅ コード重複排除
✅ 変数・関数名改善（内部スコープのみ）
✅ 型安全性向上
✅ パフォーマンス最適化（結果不変）

## 使用方法

- `/dev:refactor-safe` - 現在ブランチの修正範囲をリファクタリング
- `/dev:refactor-safe "components/auth"` - 指定ディレクトリのリファクタリング
