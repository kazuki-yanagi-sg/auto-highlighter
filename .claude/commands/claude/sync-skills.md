# スキル同期

別のプロジェクトのスキルと比較し、新しく追加されたスキルや更新されたスキルを現在のプロジェクトに同期します。

## 引数の処理

引数: $ARGUMENTS

- 引数指定時: 指定されたパスのプロジェクトと比較
- 引数未指定時: ユーザーにプロジェクトパスを質問

## 公式仕様（Claude Code Documentation準拠）

### スキルのファイル構造

**配置場所:**
- プロジェクトスキル: `.claude/skills/skill-name/SKILL.md`
- パーソナルスキル: `~/.claude/skills/skill-name/SKILL.md`

**複数ファイルを持つスキル構造:**
```
skill-directory-name/
├── SKILL.md (必須)
├── reference.md (オプション)
├── examples.md (オプション)
├── scripts/ (オプション)
│   └── helper.py
└── templates/ (オプション)
    └── template.txt
```

### フロントマターフィールド（公式）

| フィールド | 必須 | 制限 | 説明 |
|-----------|------|------|------|
| `name` | 必須 | 小文字・数字・ハイフンのみ、最大64文字 | スキル名 |
| `description` | 必須 | 最大1024文字 | 説明と使用時期 |
| `allowed-tools` | オプション | カンマ区切りリスト | 使用可能なツール |

### フロントマター形式

```yaml
---
name: your-skill-name
description: Brief description of what this Skill does and when to use it
allowed-tools: Read, Grep, Glob
---
```

### 重要な仕様

- **name**: 小文字、数字、ハイフンのみ使用可能（最大64文字）
- **description**: 「何ができるか」と「いつ使うか」の両方を含める（最大1024文字）
- **ファイルパス**: Unixスタイルのスラッシュを使用（`scripts/helper.py`）
- **自動発見**: 明示的な登録不要、配置するだけで自動認識

## 実行フロー

1. **ソースプロジェクトの確認**
   - 引数で指定されたパスの存在確認
   - `.claude/skills/`ディレクトリの存在確認
   - 各スキルディレクトリ内の`SKILL.md`の存在確認

2. **スキル一覧の取得**
   - ソースプロジェクトの全スキルディレクトリを取得（`.claude/skills/*/SKILL.md`）
   - 現在のプロジェクトの全スキルディレクトリを取得
   - 各SKILL.mdのフロントマター（name, description, allowed-tools）を解析

3. **差分分析**
   - 新規スキルの検出（ソースにあって現在のプロジェクトにないもの）
   - 更新スキルの検出（両方に存在し、内容に差分があるもの）
   - 比較基準:
     - SKILL.mdのフロントマター
     - SKILL.mdの本体内容
     - スキルディレクトリ内の追加ファイル

4. **同期対象のプレビュー**
   - 新規追加されるスキル一覧を表示
   - 更新されるスキル一覧を表示（diffも表示）
   - ユーザーに確認を求める

5. **同期実行**
   - 新規スキル: ディレクトリ全体をコピー
   - 更新スキル: ディレクトリ全体を上書き

6. **同期後のメンテナンス（必須）**
   - スキル同期後、以下を必ず確認・調整すること:
     - `description`: プロジェクト固有のトリガーワードが必要か確認
     - `allowed-tools`: プロジェクトで使用可能なツールに合わせて調整
     - 追加ファイル（scripts/など）: プロジェクト固有のパスや設定の調整

7. **同期結果の報告**
   - 追加されたスキル数と名前
   - 更新されたスキル数と名前
   - スキップされたスキル（あれば理由も）

## 同期ルール

### 新規スキル
- ソースプロジェクトにあり、現在のプロジェクトにないスキル
- スキルディレクトリ全体をコピー（SKILL.md + 追加ファイル）

### 更新スキル
- 両方に存在するスキル
- ファイル内容に差分がある場合はソースを採用
- 更新時はディレクトリ全体を上書き

### 除外対象
- 現在のプロジェクト固有のスキル（ソースにないもの）は削除しない

## バリデーション

同期時に以下のバリデーションを実施:

- [ ] `name`が小文字・数字・ハイフンのみで64文字以内
- [ ] `description`が1024文字以内
- [ ] SKILL.mdが有効なYAML形式（開始・終了の`---`、スペースインデント）

## 使用方法

- `/claude:sync-skills "/path/to/source/project"` - 指定プロジェクトから同期
- `/claude:sync-skills` - プロジェクトパスを対話的に入力

## 注意事項

- 同期前に必ず現在のブランチの状態を確認
- 同期は上書きなので、ローカルの変更がある場合は先にcommitを推奨
- スキルのdescriptionはプロジェクト固有の要件に合わせて調整が必要な場合がある
