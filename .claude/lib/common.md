# カスタムコマンド共通仕様

このファイルは、全カスタムコマンドで共通の仕様・ルールを定義します。

## 統計情報について

`.claude/command-stats.json`には以下の情報が自動的に記録されます：

- `count`: 実行回数
- `first_used`: 初回実行日時
- `last_used`: 最終実行日時
- `total_executions`: 全コマンド合計実行回数

この統計情報により、どのコマンドが頻繁に使用されているかを把握できます。

**注意**: 統計ファイルは `.gitignore` に追加されており、Git管理対象外です。ローカルでのみ保持されます。
