# Claude向けファイルの文体ルール

`CLAUDE.md`、`.claude/` 配下の `.md` 全般（`rules/`, `commands/`, `agents/` 等を含む）に適用する。

## 命令形ルール

- 指示文はすべて命令形で書け
- 終止形（〜する）で書くな。命令形（〜しろ、〜せよ）で書け
- 丁寧語（〜してください、〜しましょう）は使うな

## 命令形の変換表

| 禁止 | 命令形 |
|------|--------|
| 〜する | 〜しろ |
| 〜しない | 〜するな |
| 〜すること | 〜しろ |
| 〜してください | 〜しろ |
| 〜であること | 〜にしろ |
