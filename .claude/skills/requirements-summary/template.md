# 4見出しテンプレート

requirements-summary スキルのフェーズ2「まとめる」で参照する出力形式。

このテンプレートに沿って各見出しを埋め、そのままチャットに出力する。ルール（出典・補完可否・1行=短文 等）は SKILL.md を参照。

## 出力形式

```markdown
## 🎯 ゴール
（業務上の目的を主語＋動詞で1〜2行。情報なしとは書かない）

## 📖 背景
- （現状の不都合を1行=短文で）
- （変えたい理由を1行=短文で）
- （必要なら現状仕様を1行=短文で）
- ……
（該当情報がなければ）情報なし

## 🚫 Out Of Scope
- （やらないことを1行=短文で）
- （Claude が文脈から汲み取って書く）
- ……

## ✅ DoD（Definition of Done）
- （機能要件を入出力レベル・業務挙動レベルで1行=短文で）
- （Claude が達成条件を判断して書く）
- ……
```

## 提示直後に添える1行

```
Out Of Scope の境界線と DoD の厳しさで認識合っていますか？
```
